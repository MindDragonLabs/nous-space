API docs

Base URL: https://nous.minddragonlabs.com/api/v1. JSON over HTTPS, GET only. The index lives at /api.

Access tiers

  • Public (no key, free): current state plus records from the last 6 hours. Responses say "tier":"public","public_window_hours":6.
  • Historical (key): send X-Nous-Api-Key: <key> for records older than 6 hours. Keys are issued by the site operator.
  • Attribution: send X-Nous-Attribution: <your app name> on every call. It is required by policy. Every response also carries an X-Nous-Attribution header with the data credit — keep it with the data.
  • Limits: 60 requests/minute; poll at most once a minute. Data refreshes hourly and is edge-cached up to 5 minutes.
  • Browsers: GET responses allow any origin, but CORS preflight (OPTIONS) is not supported. Cross-origin browser code cannot send custom headers, so call from a server or CLI.
